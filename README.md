# Household-Energy-Conservation-Tracker
A project proposal for a tracking tool to conserve energy through households by calculating energy consumption and recommending doable tips to save electricity.

# About
Household-Energy-Conservation-Tracker is a project designed to let users keep track and learn about their household's electricity consumption. This is created to solve a real-world problem by helping conserve energy through a program. This system would identify the total energy consumption, top consuming appliances, and provide tips on energy conservation to the users.
